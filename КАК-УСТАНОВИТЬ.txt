ДНЕВНИК ЗАЛА — как поставить приложением
========================================
1. Распакуйте архив.
2. GitHub: новый репозиторий (Public) -> Add file -> Upload files ->
   загрузите ВСЕ файлы в корень -> Commit changes.
   Settings -> Pages -> Deploy from a branch -> main, / (root) -> Save.
   Через 1-2 минуты ссылка: https://ваш-логин.github.io/имя-репозитория/
   (или быстрее: app.netlify.com/drop — перетащите сам zip)
3. Откройте ссылку в Safari на iPhone -> «Поделиться» -> «На экран Домой».

Данные сохраняются автоматически в телефоне.
Раз в месяц жмите «Скачать копию» внизу приложения — на случай смены телефона.
